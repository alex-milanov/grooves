## Decisions (locked for MVP)

| Topic | Decision |
|-------|----------|
| **Input** | **One** shared input on the loop track (`loop.inputId`, default device). Header dropdown only. |
| **First record** | **Auto-start session** if not playing (`sessionTogglePlay` + set `transport.startTime`). |
| **Record start** | **Next bar boundary** after arm — MediaRecorder starts at that instant; `slot.startedAt` = bar time. |
| **Loop length** | **No `baseLength`.** Each slot has its own quantized `duration` (seconds). **Minimum = 1 bar.** |
| **Quantize on stop** | Trim or pad to **nearest whole bar count** (min 1): overrun **&lt; 50%** of a bar → **trim**; **≥ 50%** → **pad**. Shorter than 1 bar → **pad to 1 bar**. |
| **Overdub** | **Layer stack** — new `BufferSource` per pass; do **not** bounce to single buffer. |
| **Overdub length** | Match **existing slot `duration`** (one cycle); record window fixed, aligned to slot phase. |
| **BPM** | Playback at buffer length after quantize; global `transport.bpm` defines bar size only. |
| **Virtual click** | When first record on empty slot and drums **not** scheduling — quiet click on bar grid (+ optional 1-bar count-in before record). Skip if drums playing. |

## Quantize algorithm

```javascript
// barSeconds = (60 / bpm) * (beatsPerBar) from transport.timeSignature

function quantizeBarCount(rawSeconds, barSeconds) {
  if (rawSeconds <= 0) return 1;
  if (rawSeconds < barSeconds) return 1; // pad to 1 bar

  const fullBars = Math.floor(rawSeconds / barSeconds);
  const remainder = rawSeconds - fullBars * barSeconds;
  const fraction = remainder / barSeconds;

  if (fraction < 0.5) return Math.max(1, fullBars);
  return fullBars + 1;
}

// targetSeconds = quantizeBarCount(raw, barSeconds) * barSeconds
// trim: slice buffer 0..targetSeconds
// pad: append silence to targetSeconds
```

**Library / file assign:** run same quantize on decoded WAV length before assign (or on import click).

**Overdub:** `targetSeconds = slot.duration` (ignore nearest-bar rule for the overdub pass itself — fit take to slot cycle).

## Record flow

### Empty slot → record

1. User arms slot (round rec button).
2. If `!transport.playing` → **start session** (shared `startTime` = next bar or now — align to bar).
3. If drums not scheduling → arm **virtual click** until record starts (optional 1-bar count-in).
4. Schedule **record start** at **next bar** (`recordStartTime`).
5. User stops → stop MediaRecorder → decode → **quantize** → store buffer, set `slot.duration`, `process → play`, increment `layers`.
6. Start looping layer at `slot.startedAt` (bar-aligned, in phase with session).

### Slot playing → overdub

1. `process → overdub`; record starts at **next slot cycle boundary** (phase 0 of `slot.duration`).
2. Record for **`slot.duration`** (auto-stop) or user stop → trim/pad to **`slot.duration`**.
3. Add layer; all layers share `slot.startedAt` + `slot.duration`.

### Library assign

1. Decode WAV → quantize to whole bars → assign to slot → `process` idle or play per UX (default: idle, user hits play).

## Transport interaction

| Event | Behavior |
|-------|----------|
| Session **play** | Retrigger / resume all slots in `play` at correct phase from `transport.startTime` |
| Session **stop** | All slots → `idle`; stop sources |
| Loops track **play/stop** | Same as session-transport rules for armed track |
| **Record** while session running | `startedAt` on bar boundary; phase locked to session |
| Switch workspace | Audio keeps running (same as drums ↔ mixer) |
