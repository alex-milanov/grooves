# Theming

Grooves uses the same theming system as [iBlokz boilerplate](../boilerplate).

See the canonical documentation: [boilerplate/docs/theming.md](../boilerplate/docs/theming.md)

Fork-specific styling (sequencer, etc.) lives in `src/styles/_sequencer.scss` and consumes theme mixins/classes from `src/styles/theme/`.
